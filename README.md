# HN Digest

Summaries of Hacker News comment threads, generated by a local Ollama model and served as a static site.

## 1. Setup (once)

```bash
# install Ollama from https://ollama.com, then pull a model
ollama pull llama3.1:8b        # good default; qwen2.5:7b or gemma2:9b also work well
```

Python 3.8+ is the only other requirement (no pip packages).

## 2. Generate summaries

```bash
python3 hn_digest.py              # one pass over the front page
python3 hn_digest.py --loop 30    # keep running, refresh every 30 minutes
python3 hn_digest.py --id 12345   # summarize one specific thread
python3 hn_digest.py --model qwen2.5:7b --min-comments 30 --limit 20
python3 hn_digest.py --feeds front,ask      # only some pages (front,new,ask,show)
```

The site has four pages: top, new, ask and show, plus an about page. Set `REPO_URL` near the top of the script in `site/index.html` to show your GitHub link.

Each thread is summarized once and cached in `site/data/items/`. It is only
re-summarized if it grew a lot (30% or +25 comments) and the summary is 6+ hours old.
The first pass takes a while (about 20-60 s per thread on a laptop GPU, longer on CPU).

## 3. View it locally

```bash
python3 -m http.server 8080 -d site
# open http://localhost:8080
```

## 4a. Permanent address on Cloudflare (workers.dev)

Needs Node.js. The Worker name in `wrangler.jsonc` ("hn") becomes the subdomain, so it is
served at `https://hn.<your-account-subdomain>.workers.dev`.

```bash
npx wrangler login          # once, opens the browser
python3 hn_digest.py          # generate some summaries first
npx wrangler deploy         # first deploy, prints the URL
```

Keep it updated automatically (summarize, then deploy, every 30 minutes):

```bash
python3 hn_digest.py --loop 30 --after "npx wrangler deploy"
```

Ollama stays on your computer; only the static `site/` folder is uploaded.

## 4b. Other options (free)

**Quick link** (your computer must stay on):
```bash
# install cloudflared: https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
cloudflared tunnel --url http://localhost:8080
```
It prints a public `https://something.trycloudflare.com` URL. For a permanent
address, create a named Cloudflare Tunnel on a domain you own.

Only the static `site/` folder is exposed. Ollama stays private on your machine
and visitors never trigger the LLM, so strangers can't use up your GPU.

**Always-online alternative**: push `site/` to GitHub Pages or Cloudflare Pages after each run
(e.g. `git add site && git commit -m update && git push` at the end of a loop). The site then
stays up even when your computer is off, it just stops updating.

## Tuning for small models

- `--budget 24000` characters of comments sent per thread (about 6k tokens). Raise with `--num-ctx 16384` if your RAM allows.
- If summaries look shallow, try a bigger model or lower `--budget`; small models do better with less text.
- Env vars: `OLLAMA_URL`, `OLLAMA_MODEL`, `HN_API`, `DATA_DIR`.

## How comments are chosen

Top-level comments keep HN's own ranking. Within each, the replies with the biggest
sub-discussions are kept (up to 3 levels deep), so the back-and-forth is represented
without one huge thread using the whole budget. Each position in the summary links back
to the original comments, and the model's cited comment IDs are validated against the real ones.

`tests/mock_servers.py` is a fake HN + Ollama for testing offline.
